非公開アプリの置き場
====================

このフォルダに置いたファイルは、upload-r2.bat を実行すると
Cloudflare R2 のバケット masatools-private にアップロードされ、
https://masatools.pages.dev/admin/ の「非公開アプリ」一覧に自動で並びます。

ここに置いたファイルは .gitignore で除外されているので、
GitHub の公開リポジトリには入りません。これがこのフォルダの目的です。
（この _README.txt だけは説明のためにコミットされます）


使い方
------

1. 配布したいファイル（APK、exe など）をこのフォルダに置く
2. リポジトリ直下の upload-r2.bat をダブルクリック
3. /admin/ にログインして表示を確認する

ファイル名がそのまま一覧の表示名になります。
サブフォルダを作った場合は「サブフォルダ名/ファイル名」がキーになります。

アンダースコア（_）またはドット（.）で始まるファイルは送信されません。
このメモが一覧に出てこないのはそのためです。


初回だけ必要な準備
------------------

    npm install -g wrangler@3.114.17
    wrangler login

wrangler login はブラウザが開き、Cloudflare アカウントでの承認を求められます。


よく使うオプション
------------------

内容が変わっていないファイルは自動でスキップされます。
判定には SHA-256 を使い、結果をリポジトリ直下の .r2-upload-state.json に記録しています。

  何が送信されるかだけ確認する（実際には送らない）
      upload-r2.bat -DryRun
    これは wrangler をインストールする前でも実行できます。

  変更の有無にかかわらず全部送り直す
      upload-r2.bat -Force

  別のフォルダから送る
      upload-r2.bat -Source "C:\path\to\folder"

  R2 側のキーに接頭辞を付ける
      upload-r2.bat -Prefix "android"


ファイルを削除したいとき
------------------------

このフォルダから消しても R2 からは消えません。
Cloudflare ダッシュボードの R2 → masatools-private で対象を削除してください。
削除すると /admin/ の一覧からも消えます。
