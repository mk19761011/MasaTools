WinTimeLock

曜日・祝日・時間帯ごとにWindows PCの利用を制限できる時間管理ツールです。お子様の深夜利用防止だけでなく、自分の集中時間を守る用途にも使えます。

最新版 v1.6 をダウンロード README Vector公開ページ 匿名アンケートに答える

配布版：v1.6（2026年8月13日更新）

v1.6 の主な変更点

曜日・祝日別の利用上限

制限時間外に使える1日の合計時間を、曜日と祝日ごとに設定できます。上限を無効にしている間も利用時間を計測し、有効にすると当日の計測済み時間を含めて判定します。

解除・一時利用許可

10分、30分、1時間、6時間、翌日0時までの一時利用許可に対応しました。

5〜300秒カウントダウン

誤操作時に解除できる時間を確保しながら、動作前の待ち時間を設定できます。

監視の再適用

「保存して監視を開始」で一時許可を終了し、保存した設定を直ちに適用します。

制限時の指定動作

PCロック・スリープ・シャットダウンに加え、任意のファイルやコマンドを起動できます。

祝日設定の引き継ぎ

上書きインストール時は既存の祝日ファイルを保持するため、独自に追加した祝日を引き継げます。

ご利用前に

  • 本ソフトは強固なセキュリティ製品ではなく、家庭内での利用時間をゆるやかに管理する補助ツールです。
  • Windows 10 / 11 を想定しています。インストーラー形式で、Pythonなどを別途インストールする必要はありません。
